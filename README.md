A one-page newspaper front page summing up the world's news of
Saturday 21 November 2026: 3 illustrated lead stories (Peru M6.7 quake,
Kyiv under 400 drones and 110 missiles, Nasdaq erasing its 2026 gains),
12 more stories in brief, and 20 also-ran items — 35 stories in all,
each one an event that happened or was first reported on 21 November 2026.

Built for [make.fun](https://make.fun/c/news-image-20261121/)'s
news-image-20261121 bounty. `main.py` (Python 3.13 standard library only)
copies `entry.png` to the output directory.
